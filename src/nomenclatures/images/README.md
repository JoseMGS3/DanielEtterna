# Reform 4K Images nomenclature

Upload the 100 files here (src/nomenclatures/images/) without renaming them.
1-10: number-low.svg, number-mid-low.svg, number.svg, number-mid-high.svg, number-high.svg.
alpha-kappa: alpha-low.webp, alpha-mid-low.webp, alpha.webp, alpha-mid-high.webp, alpha-high.webp.
Repeat the pattern for all numbered and Greek Dans (50 SVG + 50 WebP).

Alternatively, for Windows EXE builds, use:
%LOCALAPPDATA%\DanielEtterna\nomenclatures\images\
The program creates this directory automatically. Local files take priority.
Images uses Mania tracker's 5 subdivisions and does not change DP.
Unrenderable/missing files fall back to readable text.
SVG requires CairoSVG; WebP is supported by Pillow.

Original assets: https://github.com/aleju03/mania-hub/tree/main/public/images/dans/reform
Before redistributing them, verify graphics licensing and preserve notices.
